# 🛒 Amazon Clone (Responsive Frontend Project)

A responsive front-end Amazon style e-commerce website created using HTML and CSS.  
The aim of this project is to learn how to create a responsive layout and UI.

---

## 🚀 Live Site

👉 https://amazon-clone47-kareem.netlify.app/

---

## 📌 About This Project

This project is a responsive front-end clone of an e-commerce website inspired by Amazon.  
This site was created to help practice the following skills:

- Responsive design
- Layout creation using HTML & CSS
- UI recreation
- Creating a responsive design

Some elements were removed to focus on learning rather than creating functional features and back-end code.

---

## 🛠️ Built With

- HTML5
- CSS3
- Flexbox
- Responsive Design principles

---

## 📱 Features

- Responsive design
- Amazon style layout
- Navigation bar
- Product sections

---

## 🎯 Purpose

This website was created to practice front-end coding and UI design skills.
